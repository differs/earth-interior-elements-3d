# 地理层：容易开采的"宝藏"分布 (geo_distribution)

## 定位

径向模型回答"**地心到地表：每种元素在哪个深度、有多少质量**"；
生成窗口文档回答"**什么 P-T 环境会把它富集起来**"；
地理层回答第三个问题——"**这些已经富集起来、又容易开采的宝藏，在星球表面
的哪些地方**"。

## 方法（大胆假设 + 仔细标注）

1. **地面真值 = 世界级矿床/油气省**：
   勘探圈已经跑了上百年，"已发现的世界级矿床"本身就是地下浅部生成窗口
   真实打开过的**最强指示**。因此本层不预测"哪里可能有"，而是先老老实实
   盘点**已知宝藏在哪**（54 个固体金属省/区带 + 16 个油气煤省，含坐标、类型、
   开采方式、置信度、出处列）。
2. **易采性分层**：按 `access`（开采方式）给 1-5 档
   - 卤水抽取/井采/露天 → 最易（Li 盐湖、石油、露天铁/金/铜）
   - 原地浸出 → 易（铀砂岩、离子吸附稀土）
   - 地下浅井 → 中
   - 地下深井（如 Witwatersrand >3km）→ 难
   - 海上深水（巴西盐下）→ 深水难
3. **与立体模型挂钩**：每条记录挂上主元素的 **EF(地壳/地幔富集因子)**。
   直觉校准：EF 高 = 岩浆/热液把该元素泵到浅表能力强 = 更容易在地表附近碰到
   成矿省；EF 低但仍在浅表形成巨矿的（如 Fe、Ni 红土）说明**需要特殊富集机制**
   （BIF 大规模沉淀、风化富集）而不是简单的"壳/幔富集"。

## 你能从这里得到什么

- `outputs/geo_deposits_processed.csv`：世界级金属省全表（名称/国家/主副金属/
  地质类型/开采方式/坐标/规模量级/置信度/出处 + EF）
- `outputs/geo_hydrocarbon_processed.csv`：超级油气/煤省
- `outputs/geo_family_summary.csv`：按金属族统计（多少省、哪些国家、可采中位数档）
- `outputs/geo_world_map.png`：世界分布图（底图 Natural Earth 110m，公有领域）

## 有意思的"分布规律"初读

| 金属族 | 位置规律（tectonic/geologic 逻辑） | 开采难易 |
|---|---|---|
| Au | 太古宙绿岩带(西澳/阿比提比/西非) + 卡林型(俯冲热液) + 黑色页岩型 | 中(露天+地下) |
| Cu | 环太平洋俯冲带斑岩带(智利/印尼/蒙古) + IOCG + 沉积铜带 | 露天多,较易 |
| Fe | 前寒武纪 BIF(皮尔巴拉/卡拉加斯/克里沃罗格) 大型风化富集 | 露天,最易 |
| Ni/Co | 大火成岩省岩浆硫化物(诺里尔斯克/萨德伯里) + 热带红土(新喀/印尼) | 中 |
| Li | 安第斯盐湖卤水 + 伟晶岩(西澳/刚果) | 卤水最易(挡5) |
| REE | 碳酸岩(白云鄂博/芒廷帕斯) + 中国离子吸附型(华南) | 碳酸岩/离子吸附较易 |
| PGE | 层状杂岩体(布什维尔德占~70%) | 地下,较难 |
| U | 不整合面型(阿萨巴斯卡高品位) + 砂岩地浸(哈萨克) | 地浸易 |
| 金刚石 | 古老克拉通根上的金伯利岩筒(南非/博茨瓦纳/西伯利亚/加拿大) | 露天+地下 |
| 油气 | 被动陆缘/克拉通内/三角洲巨型盆(中东/西伯/二叠盆/深水盐下) | 井采为主 |

规律与径向模型/生成窗口完美互洽：**金刚石只出现在 ≥150 km 深克拉通根的
金伯利岩里**（生成窗文档的克拉通根一行），**油气集中在沉积盆地的生油/生气窗**，
而最容易露天采的 Fe 正是那些被风化"再富集"的前寒武纪 BIF。

## 局限与诚实声明

- 坐标是**省/区带质心，±1.5° 近似**，用于全球尺度看图与统计，**不可**用于矿床
  精确定位（那需要接 USGS MRDS 等逐矿点库）。
- 只收录"世界级"名单（每个金属族 3-10 个代表省），不是全球普查。
- 规模量级为"数量级口径"，不同来源口径(储量/资源量/累计产量)未统一，请以原始
  出处(USGS Commodity Summaries / 公司年报)为准复核。
- 置信度列区分 high/medium；high 为多来源可交叉的著名省。
