# 地球内部的"宝藏"：从地心元素分布到地面立项卡

## ——一套可复算的找矿前置方法综述（v0.3j, 2026-09）

> 一句话：本仓库把"地球内部每种元素有多少、藏在多深"（存量）与
> "地表哪里已富集、哪里容易被挖、哪里值得再去复查"（可及性）串成
> 一条**全可复算、每步带出处与置信级**的推理链，并在末端产出可直接派活的
> 立项卡与建议书。它**不是**矿床预测器——它是把找矿从"拍脑袋"变成
> "假设 + 证伪清单"的前置科学方法。

## 1. 目标与三条铁律

地球内部是人类物理上最大的"仓库"，但它被 5–2,900 km 的岩石隔开。真正能利用的，
只有被搬运到近地表、又在"可采窗口"里富集出来的那一小部分。因此本方法把问题拆成
五个递进层次：

```
① 存量   元素在哪个深度、以多少质量存在      → 1D 分层元素模型
② 富集   什么 P-T-化学窗口能把它们富集      → EF 富集因子 + 生成窗
③ 已知   已经富集并被开采的世界级矿在哪      → 世界级省库 + MRDS 等
④ 邻域   高分但未记录的格(欠勘查候选)在哪   → 规则版潜力评分
⑤ 立项   哪些格值得派人回去复查、怎么查     → 观察清单 + 立项卡 + 建议书
```

三条铁律贯穿始终：
1. **大胆假设，仔细推导**——所有"敢"都被编号成 H-1…H-9 并写明"若推翻改哪里"
   （`docs/hypotheses.md`），其余尽量贴着教科书数据走。
2. **未建模不臆造**——任何一行数字都能溯源到 `data/` + 出处表；没把握就标置信级，
   不凭空编 ppm/坐标。
3. **候选 ≠ 矿**——输出永远带"先证伪再立项"的操作纪律。

## 3. 第一层·存量：元素在地球内部的立体分布

### 3.1 几何与质量守恒（`layering.py` / `build_models.py`）

地球被剖成近似 PREM 的同心球壳(地壳≈21.6 km / 上地幔 410 / 过渡带 660 /
下地幔 / 外核 2,891 / 内核 5,150 km)。三个质量区(壳/幔/核)的质量锁定为文献目标，
对基准密度剖面做单区缩放使体积积分**精确等于**地球质量 5.972×10²⁴ kg：

| 区 | 目标质量 (kg) | 几何偏差 |
|---|---|---|
| 地壳 | 3.20×10²² | **0.000%** |
| 地幔 | 4.002×10²⁴ | **0.000%** |
| 地核 | 1.939×10²⁴ | **0.000%** |

缩放系数全部落在 0.99–1.01 之间——密度剖面不是硬凑的，这是"仔细推导"的第一个证据。

### 3.2 成分数据

- 地壳：CRC97 全元素质量 ppm（真表）；
- CI + BSE：McDonough & Sun (1995) 全元素表（解析脚本处理 %/ppb 单位混乱 + 氧差反算，
  两列都严格归一到 1e6 ppm）；
- 地幔：**BSE 扣除地壳的质量平衡解**，避免"壳+幔各用原岩丰度"的重复计算；
- 地核：由核幔质量平衡反演(见 3.4)。

### 3.3 富集因子（EF）

令全球平均地壳丰度 c_crust、地幔 BSE 丰度 c_mantle：

```
EF = c_crust / c_mantle
```

EF ≫ 1 = 该元素被岩浆分异/流体搬运"泵"到浅表 → 浅层成矿潜力高；
EF ≈ 1 = 自然分配；EF ≪ 1 = 相容/亲铁，大量存量锁在深部。
`outputs/enrichment_crust_vs_mantle.csv` 是全仓库第一个可查询的"立体分异"量。

### 3.4 核幔质量平衡反演地核（`inversion.py`，最漂亮的一步）

难挥发亲石元素(Al/Ca/Ti/Sc/Y/Zr/Hf/Nb/Ta/Th/U + REE，25 个样本)不受核幔分异影响，
从它们可锁定**全地/CI 富集系数**：

```
X_ref = mean_i[ (M_sil/M_E)·(BSE_i/CI_i) ] = 1.8495 ± 0.24%  (样本内弥散极小!)
```

再把强亲铁金属(Fe/Ni/Co/Cr/W/Mo/Re/Os/Ru/Rh/Ir/Pt/Pd/Au)以同一 X_ref 从 CI 继承
全地丰度，差分即得地核浓度：

```
c_core,e = (X_ref·c_CI,e − F_sil·c_BSE,e) / F_core
```

结果与文献(McDonough 2003)吻合到 ~1.5 个百分点内：
**Fe 84.1%(文献 85.5)、Ni 5.57%(5.2)、Co 0.26%、Cr 0.96%**。
随之得到一组反直觉但正确的"宝藏归宿"：

> **Au/Pt/Pd/Os/Ir 地球储量的 >99.7% 在地核；Fe 86.6%、Ni 93.2% 在地核。**
> 地壳里那点金，是 46 亿年岩浆/热液从"几乎全被核拿走"的剩余里再捞出来的——所以 EF 高
> ≠ 存量高，存量高 ≠ 可采。这是本方法反复强调的"可及性"问题的物理根源。

### 3.5 生成窗（`docs/generation_windows.md`）

生油窗 2–6 km、生气窗 6–10 km、斑岩热液带、克拉通根 150–200 km 的金伯利岩窗、
核幔边界超深窗……"存量×窗口"才是产状。这一层目前是定性表，v0.2/0.3 的下一步是把
P-T 剖面做成连续函数与径向表合并查询。

## 4. 第二层·已知"宝藏"的地理分布

径向模型回答"在哪个深度"，地理层回答"在哪个经纬度"（`geo.py` / `build_geo.py`）。

- **世界级固体金属省 54 个 + 油气/煤超级省 16 个**，带坐标(质心 ±1.5°)、地质类型、
  开采方式、规模量级、置信度与出处；
- 开采方式映射成"易采档 1–5"：卤水/井采/露天最易，地下深井/深水最难；
- 每个省挂主元素的 EF，把立体模型与地理锚点串起来。

图上能直接读出与生成窗互洽的规律：金刚石只在古老克拉通根的金伯利岩筒；
斑岩铜贴在环太平洋俯冲带；油气锁定沉积盆地生油生气窗。

## 5. 第三层·从"已知"外推"该再看的邻域"

### 5.1 锚点体系

用 MRDS(18.6 万) + 全球专家汇编(1.0 万) + PP1802(905) + 世界级省(70)
做正样本。专家汇编与 PP1802 专门用来**抵消 MRDS 的美国偏重**：
China 覆盖 505→1080、Russia 1162→1767。

### 5.2 isotropic → 规则版（`prospect.py`）

第一版是各向同性高斯"富集引力"（2° 网格 σ≈4°，百分位 + P90 前沿格）。
第二版升级为**构造规则加权**——用真实 GVP 火山按 Tectonic Setting 分弧/裂谷做距离核：

```
score(格) = α·nearAnchor + β·nearArc + γ·nearRift
```

权重表每条带 EF/生成窗理由（`prospect_rules_weights.csv`），并有金刚石"远离弧"这类
**负规则**。语义变化已被抽查验证：Cu 前沿转到弧区无矿格(新几内亚/意大利弧)，
金刚石回到远离弧的克拉通内部。

v0.3h 把评分族从 11 扩到 **20**(新增 Zn-Pb/Cr/Mn/W/Sn/Sb/V/Ti/Ta-Nb)，
数据来自 podchrome/sedznpb/PP1802 临界金属/MRDS 商品词；分类器对 tin/lead/zinc 等
短词用词边界匹配防误命中。

### 5.3 前沿格（frontier）

`前沿格 = 分数 ≥ P90 且 2° 内无已知锚点`。诚实定义：这是"已知富集的空间平滑 +
欠标记格挖掘"，**不是**未发现矿床的预测；高分只说明"地质上像有货、又没被记录，
值得回去翻图"。

## 6. 第四层·可采性过滤与数据空洞（`watchlist.py` / `build_watchlist.py`）

前沿格的最大假象不是地质，而是两类工程/数据噪声——**海上与冰盖**、**数据库欠报国**。
观察清单给每个前沿格附加：

1. **可采性**：陆地(NE) / 冰盖 / 极地(≥72°) / 最近主要城市 km；
2. **数据空洞**：所在国公开库(MRDS+专家+PP1802)条数 vs 世界级省数 → reporting_gap
   （国名中英别名表含"新墨西哥≠墨西哥"防误判）；
3. **现役采矿证据**：该国 Maus 采矿多边形数(`mining_polygons_n`)——帮区分
   "欠报但确在开采"(俄/中/加)与"真数据荒漠"(如刚果)。

当前分派(20 族)：**数据空洞优先核验 417 / 标准复查 811 / 海上 1,053 / 极地冰盖 4**。
输出 `outputs/reexploration_watchlist.csv`(+地图/meta)。

## 7. 第五层·立项

- **立项卡**(`reexploration_dossiers.md/.csv`)：把各族 top 候选格聚合成
  EF + 生成窗 + 规则理由 + 采矿证据 + 物流 + "下一步动作"的一行行可派活结论；
- **5 份一页纸立项建议书**(`proposal_briefs.md`)：从高分候选挑出的代表格，
  每份含完整证据表 + 立项逻辑 + 主要风险：
  苏门答腊 Sn-W、阿拉伯地盾 REE-Ta-Nb、巴布亚弧 Au、墨西哥 SMO 锑、阿拉伯地台油气复查。

所有文档头部都写死三条纪律：**先该国 1:20 万–1:5 万图/矿权/保护地复核 →
航磁-重力-化探复核 → 已知邻区踏勘对照**。

## 8. 诚实边界与失败模式（必读）

1. **不是矿床预测器**。我们把"看哪里"做成了科学，但"那里到底有没有矿"只能由
   物探/钻探回答。矿业界真实命中率约千分之一量级——这份清单只是把基数从
   "全世界"缩到"几百个可核查格"。
2. **MRDS 美国偏重仍在**。即使并入专家汇编与 PP1802，美国外的高分格数量仍被低估；
   `reporting_gap` 标注的是"收录缺口"，不是"真实矿数差"。
3. **2° 网格与质心坐标**用于全球尺度统计，**不可**用于精确定点；省/区带坐标
   ±1.5° 质心，须以官方 GIS 复核。
4. **规则是启发式的**：arc/rift 用 GVP 火山代理(含热点)；克拉通与沉积盆地掩码
   因缺全球免费档仍缺席(金刚石/油气靠锚点+负/弱规则间接表达)。
5. **"高分邻域"语义陷阱**：前沿格常紧贴已知矿团，是"已知的边际"，不等于绿野新地；
   高分也可能落在海底、保护区或早已探明未商业化的格(建议书已把这点写进风险)。
6. **授权数据门**：中国矿产地库/俄 1:2.5M/非洲统一库定位到了入口但需账号/申请，
   未入仓(`docs/data_gap_catalog.md`)。
7. **不该做的事**：不要用"前沿格命中率"宣称模型有效(正样本内训)、不要把单格高分当
   投资依据、不要在未查权属前把任何一格里说成"发现了矿"。
